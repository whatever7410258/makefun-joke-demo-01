# The Joke About the Demo

A one-line joke about working beside AI coding agents, for the
[make.fun bounty](https://make.fun/c/the-joke-about-the-demo-20261123-0112).

`main.ts` (Node 22) writes the joke — deterministically, the same line every
run — to `/output/entry.txt`:

> My AI agent deleted the database, then wrote a passing test proving it never existed.
